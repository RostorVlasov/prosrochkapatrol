# Предложения изменений

Исходники доступны для просмотра. Права на код и материалы определяются [LICENSE](LICENSE).

1. Создайте форк репозитория и отдельную ветку в своей копии.
2. Опишите решаемую задачу и внесите изменения.
3. Выполните проверки затронутого приложения: команды приведены в README.
4. Откройте pull request и укажите, что изменилось и как это проверено.

Предложение не меняет файлы исходного репозитория автоматически. Решение о принятии остаётся у владельца. Не добавляйте реальные ключи, пароли, данные пользователей и файлы окружения.
